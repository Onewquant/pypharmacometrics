## 1. 개인 CL 산출 오류와 교정: 난수 기반 η → 실측 기반 추정치(EBE)

**발견한 문제.** PGx 분석에 쓴 개인 CL은 시뮬레이션 출력(run 90)에서
가져오고 있었습니다. 그런데 이 시뮬레이션은 `$SIMULATION ... ONLYSIM`
구문으로 실행되어, 개인 편차(η)를 각 환자의 관찰 농도에서 추정한 것이
아니라 **분포 N(0, ω²)에서 난수로 생성**하는 구조였습니다. 즉 산출된 개인
CL은 "그 공변량을 가진 가상 환자"의 값이었고, 실제 환자의 혈중농도 정보가
반영되어 있지 않았습니다.

- 시뮬레이션 유래 η vs 최종모델 추정 η(EBE) 상관계수 **−0.076** (무관)
- 예: ID 78의 관찰 농도 기반 CL은 0.347 L/day인데 시뮬레이션에서는
  0.609 L/day(코호트 최대)로 배정됨
- 모델 코드(`CL = TVCL * EXP(ETA(1))`) 자체는 정상이며, 시뮬레이션 모드에서
  같은 코드가 η를 난수로 생성하는 것이 문제의 지점이었습니다. 이전에
  결과가 환자 1~2명의 포함·제외나 체중 1건 교정에 크게 흔들렸던 현상과도
  일치합니다.

**교정 방법.** 최종모델(run 89)을 재추정하여 얻은 개인별 posthoc η(EBE)를
시뮬레이션 데이터셋에 변수로 투입하고, 개인 CL을 다음과 같이 산출하도록
바꾸었습니다(run 95).

```
CL(t) = TVCL(시점 t의 공변량) × exp(η_EBE)
```

체중·알부민·ADA 등 시변 공변량에 따라 치료 시기별 CL이 달라지는 설계
의도는 그대로 두고, **개인 편차 항만 난수에서 실측 기반 추정치로**
교체한 것입니다. 새 시뮬레이션의 개인 η와 EBE의 상관계수는 **r = 1.000**
입니다.

**popPK 모델 자체는 변동 없음.** 최종모델 재추정 결과는 기존과 동일했습니다
(OFV −935.665, 소수점 12자리까지 일치). 앞서 발견한 체중 입력 오류(834 kg)는
해당 투여기록 이후 다음 관찰까지 약 1,200일 간격이라 모델 적합에 기여하지

## 2. 최종 결과: FDR 보정 후 유의한 변이 없음
