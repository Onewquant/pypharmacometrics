1. 연구 대상 (Figure 1, Table 1)

- 분석 코호트 139명 → infliximab 기록이 없거나 평가 가능한 농도가 없는
  42명 제외 → infliximab PopPK 모델링 코호트 97명 → 유전형 QC에서
  시료 제거 1명 → 약물유전체학 분석 코호트 96명
- 약물유전체학 분석은 전체 치료기간 96명, 유도기 83명, 유지기 96명
- Table 1은 분석 코호트(139명)와 PopPK 모델링 코호트(97명) 두 열입니다.
  PopPK 코호트: 여성 25명(25.8%), 소아 16명(16.5%), 평균 연령 32.4세,
  체중 67.1 kg, CD 67명 / UC 30명, 유도기 자료 있음 83명 / 유지기 시작
  14명, 혈중농도 검체 393건, ADA 양성 9명(9.3%, 추적기간 전체 기준)

2. 집단약동학 모델 (Table 2, Figure 2, Supplementary Figure S1–S2)

- 정맥·피하 통합 2구획 모델. 청소율에 ADA·성별·체중, 중심 분포용적에
  알부민·체중 공변량. 최종 파라미터는 Table 2(부트스트랩 포함).
- 모델 평가: 적합도 플롯(Supplementary Figure S1)과 VPC(Supplementary
  Figure S2, 200회 시뮬레이션·8구간)를 보충자료로 추가했습니다.
- 약물유전체학 분석의 개인 청소율은 최종 모델의 경험적 베이즈 추정치(EBE)에
  시변 공변량(체중·알부민·ADA)을 결합해 산출하고, 각 분석 기간의 중앙값으로
  요약했습니다(Methods에 산출 방법과 분석 기간 창 정의 기술).

4. 약물유전체학 결과 (Table 4–5, Figure 3, Supplementary Table S1–S4, Figure S3)

FDR 보정 후 청소율 또는 ADA 양성과 유의하게 연관된 변이는 없었습니다.
사전 정의 검정 225개(청소율 150, ADA 75) 중 26개(유도기 ADA)는 양성 환자가
없어 추정 불가, 199개 산출, q < 0.05는 0건입니다. Figure 3은 전체 치료기간
25개 비교(열성 11, 우성 14)의 GMR·95% CI·p·q를 한눈에 보이는 forest plot입니다.

명목상 유의(비보정 p < 0.05)한 것은 FCGR3A rs396991 열성 모델 하나뿐이며,
세 분석 기간에서 방향이 일관됩니다(Table 5, Supplementary Figure S3).

    분석 기간    CC (n)  기하평균 CL, CC vs A 보유자 (L/day)  GMR (95% CI)      P      q
    유지기      5       0.396 vs 0.284                1.36 (1.09–1.71)  0.009  0.098
    전체 치료기간  5       0.376 vs 0.280                1.32 (1.06–1.64)  0.014  0.157
    유도기      4       0.356 vs 0.277                1.35 (1.05–1.72)  0.020  0.218

다만 CC 동형접합이 5명뿐이고, 한 명씩 제외하는 leave-one-out에서 어느 한 명을
빼도 명목 유의성이 사라지므로(최대 P 0.112 유지기 / 0.141 전체 기간,
Supplementary Table S3) 가설 생성 수준으로 기술했습니다. 우성 모델은
비유의(GMR 1.08, 95% CI 0.98–1.20, P = 0.134)입니다.

ADA 양성: 어느 변이도 연관 없음(최소 P 0.076, q > 0.99; Supplementary Table
S2). 분석 기간 내 ADA 양성은 6명이고 유도기 창에는 없어 검정력이 매우 낮습니다.
Table 1의 ADA 9명은 추적기간 전체 기준으로, 3명은 1년차 유지기 창 이후에
양성 전환한 환자입니다(원고에 정의 구분 기술).
